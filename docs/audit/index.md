# docs/audit — 監査記録（audit）

ここは**過去に何が起きて、何を記録したか**の時点記録です。
設計方針（`../arch/`）や進行中の計画（`../planning/`）とは別物です。

## このフォルダに置くもの

- `diff-{context}.md` : 計画・仕様と実装の差分の監査記録
- `issues-{context}.md` : 過去に確認した問題・リスクの監査記録
- `activity.md` : 重要な変更の追記式ログ（いつ・何を変更したか）

## 運用ルール

- **時点記録**：作成した時点の事実を書く。後の発見で上書きしない
- **追記式**：`activity.md` は新記録を上단에追記（最新在上、加えても削除しない）
- **結論を明示**：各記録の末尾に「採用 / 不採用 / 要確認」を必ず書く
- 設計変更は `../arch/` へ、タスク状態は `../task-list.md` へ反映
- ファイル名は短く正確、ハイフン最大1つ
